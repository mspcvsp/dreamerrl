# CAGE2 bounded history follow-up

**Conditional GO for one frozen flat-checkpoint investigation after approval. Broad representation evaluation and hierarchy comparisons remain NO-GO.** Begin with a development-only common-support check. If it fails, close this line of investigation on the present archive. One positive test would support a subsequent flat replication for the specified target.

## Evidence and target choice

The labeled pilot reproduced the saved actions, rewards and truncation flags on 24 B-line episodes from the matched flat seed-0 checkpoint. Its Enterprise2 active-session target was already 98.08% decodable from current observations on the five test episodes. Adding h improved balanced accuracy by 1.92 points, with a paired 95% interval of 0–4.35 points. Time alone reached 90.32%. Repeating the same unrestricted active-session comparison would leave little headroom and retain its time confound.

The best candidate is **recent Enterprise2 session history when the host is currently inactive**. From the saved labels, 22 of 24 pilot episodes provided at least one such recent positive and 24 provided a negative. There were 196 positive and 263 negative eligible frames. Nineteen decision times had both outcomes. By comparison, an equivalent Enterprise1 target had only 52 positive frames across 11 episodes. A never-active versus previously-active Enterprise2 comparison would have only two never-active pilot episodes. Neither alternate is part of the confirmatory test. Current active-session status remains a separate future target if matched support can be demonstrated.

Predeclare the single binary target at pre-action frames t = 4 through 29. Include a frame if simulator truth reports no active Red session on Enterprise2 at t. Label it positive if Enterprise2 hosted at least one active Red session in t−4 through t−1 and negative otherwise. Use the existing offline active-session label adapter. Privileged truth supplies inclusion and labels only. The policy and model receive archived actions and ordinary Blue observations. The result will measure recoverability of recent hidden history conditional on current inactivity.

The pilot establishes ambiguity at equal elapsed time. Its saved label file contains no aligned current Blue observations, so ambiguity under the full current input is unverified. Exact matching on all 52 Blue bits, elapsed time and the incoming Blue action addresses this directly. Within an opposite-label pair with identical current inputs, a deterministic current-input predictor must tie. This conclusion applies to the matched population.

## Fixed analysis plan

The [proposed machine-readable plan](../environments/cage2/history_common_support_plan.json) pins the checkpoint, archived input fingerprints, split memberships, and thresholds. Exclude all 24 labeled-pilot episodes. Order the remaining 76 archived B-line seeds by the specified SHA-256 rank and reserve 28 for fit, 12 for validation and 36 for test. Freeze the host, target, eligibility, matching keys, model and split before collection. No replacement seeds or additional opponents enter the study.

- **Support gate.** Start with the 40 development episodes. Within each split, build edges between different episodes if an eligible frame from each has identical current inputs and opposite labels. Pick a maximum-cardinality set of episode-disjoint edges using sorted seeds and a fixed lexicographic tie rule. For a selected edge choose the earliest qualifying frame. Use each episode at most once per split. Pairing uses current inputs and offline labels. History features and scores are unavailable to the matcher. Require at least **10 fit and 4 validation pairs**, and **12 test pairs** after model lock. Report frame and episode counts, match yield and reasons for exclusion. The test can yield at most 18 independent pairs.
- **Readouts.** Use the shared frozen flat Dreamer filter. The primary class-balanced linear ridge probe adds full recurrent h to the common current inputs. Controls use current inputs alone and h computed with zero carry and the same incoming action. A secondary linear probe adds the preceding four raw Blue frames and actions to the common current inputs. It helps distinguish a weak frozen recurrent readout from a weak target. Fit on matched development rows, select ridge penalty on validation, and use the strongest regularization for exact validation ties. The current-only and fixed-carry scores must tie on every matched pair within 1e−8. Require correctly ordered full-history scores on at least 75% of validation pairs before opening the test cohort. Lock preprocessing, weights and penalty at that point.
- **Primary statistic.** Compare scores within each held-out pair. An ordering is correct when the positive frame scores higher. Count exact score ties as failures for the primary. Report the proportion of correctly ordered pairs, tie count and two-sided 95% Clopper–Pearson interval across disjoint episode pairs. Interpret the interval under exchangeability and independence of pairs in the matched sample. Report the raw-history result as descriptive, along with time-only/current-input tie checks. No test-label tuning or post hoc substitutions.
- **Acceptance.** Require complete archived-action, reward, available reward-component, and truncation parity on all included episodes. Require match-support and leakage gates to pass, held-out pair accuracy of at least **75%**, and the exact lower confidence bound above **50%**. At the minimum support, 10 correct out of 12 clears both accuracy criteria. This deliberately tests for a large history effect. A smaller or imprecise result cannot clear the broad evaluation gate.

## Budget and decision

Reuse the validated flat v4 checkpoint at update 16,899 and the matched B-line archive. Cap execution at 76 episodes, 2,280 native steps, one sequential CPU worker with two threads, 20 minutes, 4 GiB working memory and 256 MiB of output. Stop after 40 episodes if development support, parity or validation performance fails. Cache aligned inputs and labels in the new ignored run directory. Use detached tmux and the existing supervisor and thermal watchdog. Write the gate outcomes, paired scores, split IDs, report and completion manifest on exit.

**A pass supports a narrow GO for a separately reviewed flat replication of this exact historical target.** It does not establish a current-compromise forecasting benefit, actor or critic utilization, a need for attention, or generality across opponents and architectures. If exact matching leaves too few independent pairs, the current archive cannot support the claim. Close out this cohort and record richer observation-matched trajectories with independent class support as future work. If coverage is adequate but the primary criterion fails, keep broad evaluation at NO-GO. A stronger raw-history readout would motivate future work on representation retention.
