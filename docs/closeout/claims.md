# Evidence-to-claim traceability

Run IDs and paths are defined in the [artifact inventory](artifacts.md). **Established** refers to measurements under the recorded conditions. **Local** denotes a fixed-checkpoint intervention or observed cohort association. **Inconclusive** denotes an estimand the evidence cannot resolve. **Hypothesis** denotes a proposed mechanism.

| T1-E · Encoding | T1 `checkpoints/seed{19,23,29}_4000.json` and `diagnostic_results.json`. On 16 held-out level pairs per seed, reset cue accuracy was 100% in raw/preprocessed input, encoder, raw logits, and pre/post-unimix probabilities. | **Established for this T-maze.** Posterior decodability allows a weak probability difference. It does not quantify how much reaches a draw. |
| T1-Z · Transmission | Same T1 records, per-seed `separation` and `latent`. Exact paired argmax equality. Sampled linear accuracy 50%; RBF 50.04% aggregate; single-draw Bayes upper bounds 50.07–50.18%. | **Established for the tested inputs and checkpoints.** Bounds assume two equiprobable cue conditions, independent posterior factors and one draw with pair context available. Interpretation priority is stage-specific. A representation can carry a decodable signal without a useful downstream response. Conditional carry sensitivity can exist without establishing which labeled fact drove the response. A support failure limits the comparison that can be made.
